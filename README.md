# Calculator App

A responsive calculator built with HTML, CSS, and Vanilla JavaScript.

## Features

- Basic arithmetic operations
- Delete and reset functions
- Calculation history
- Undo previous results
- Three different color themes
- Saves theme and calculation history using Local Storage
- Responsive design

## Technologies

- HTML5
- CSS3
- Vanilla JavaScript
- Local Storage
